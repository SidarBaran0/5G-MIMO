# 5G-MIMO
DAT610 project – 5G NR MIMO simulation using MATLAB

## Simulation procedure

The simulations were performed using the same MATLAB script. The simulation parameters were manually adjusted between runs to evaluate five different MIMO configurations under both TDL-C and CDL-C channel conditions.

The antenna configuration, number of transmission layers, and channel model were changed between simulation runs.

## Performance metrics

The simulations evaluated the following performance metrics:

- Normalized throughput
- Block Error Rate (BLER)
- Spectral efficiency

The results were recorded and used in the project report.

## Software

- MATLAB R2022a
- 5G Toolbox
